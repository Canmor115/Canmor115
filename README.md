## 🔭Projects

### 📊 Self-employment in the EU (2010–2024)
Exploratory analysis of self-employment across Europe using open Eurostat data. Interactive maps by NUTS 2 region, gender analysis, education level and correlation with unemployment rates.
Python Pandas Folium Seaborn Eurostat API.  

`Python` `Pandas` `Folium` `Seaborn` `Eurostat API`

### 🏦 Credit Risk Prediction
Classification of credit applicants (German Credit dataset) using decision trees and ensemble models, evaluated under an asymmetric cost matrix (FN=5, FP=1). Explainability analysis with Feature Importance, ALE and SHAP values. Highest-risk profile identified: applicants with a negative balance requesting long-term loans.  

`R` `C5.0` `Random Forest` `XGBoost` `SHAP` `ALE`

### 💰 Who manages public finances better? (1995–2024)
Analysis of 30 years of IMF fiscal data across 182 countries. Built three custom metrics (fiscal health index, fiscal dynamics, vulnerability score) and an interactive Tableau dashboard with linking & brushing. Key finding: a country's wealth doesn't predict its fiscal health.  

`Python` `Pandas` `Tableau` `Flourish` `IMF API`
